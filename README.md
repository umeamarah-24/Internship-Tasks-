# Internship Tasks – HTML, CSS & JavaScript

## Overview
This repository contains two web development tasks completed as part of my internship. These tasks helped me practice HTML5, CSS3, JavaScript, DOM manipulation, and basic web development concepts.

## Task 1: Semantic HTML & CSS Personal Resume

### Description
Created a clean and well-structured digital resume using HTML5 and CSS3. The resume presents personal information, skills, education, and experience in an organized layout.

### Features
- Semantic HTML5 elements for better structure and accessibility.
- Organized sections for personal details, education, and skills.
- Clean and attractive CSS styling.
- Responsive layout for different screen sizes.
- Professional resume design.

### Technologies Used
- HTML5
- CSS3


## Task 2: Interactive JavaScript Quiz Game

### Description
Developed an interactive multiple-choice quiz game using JavaScript. The quiz displays one question at a time, checks selected answers, tracks the score, and displays the final result.

### Features
- Multiple-choice questions with different options.
- Questions and answers stored in a JavaScript array of objects.
- DOM manipulation to dynamically update questions and options.
- Automatic score calculation.
- Final result screen with feedback based on the score.
- Restart Quiz functionality.

### Technologies Used
- HTML5
- CSS3
- JavaScript

## Learning Outcomes
Through these tasks, I learned:
- How to create structured web pages using HTML5.

- How to style web pages using CSS3.
- How to make web pages responsive.
- How to use JavaScript for interactive functionality.
- How to manipulate HTML elements using the DOM.
- How to store and manage quiz questions using JavaScript objects and arrays.
- How to handle user interactions and calculate scores.

These internship tasks provided practical experience in frontend web development. They strengthened my understanding of HTML, CSS, and JavaScript and helped me develop simple, user-friendly, and interactive web applications.
